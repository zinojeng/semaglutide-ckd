# 05｜從病例到決策：五種表現型、22 問、證據缺口與治療演算法

> 範圍：依 SHA-256 `75368cba…98cd56` 的凍結總論精煉；證據截止 2026-09-05。本文是臨床學術整理，不是個人化醫療建議。

## 一句話先說結論

Semaglutide 在符合 FLOW 的 T2D＋白蛋白尿性 CKD 病人中，已有臨床重要結果的隨機證據；但處方是否迫切、排在何時，以及能否和 SGLT2i／finerenone 加成，必須由表現型、可耐受性與尚未解答的證據缺口共同決定。

## 決策前的三個校正

1. FLOW 的主要結果是**含 CV death 的五項複合終點** HR 0.76（0.66–0.88）；排除 CV death 的四項腎臟專屬終點 HR 0.79（0.66–0.94）是支持性、位於確認性階層之外的結果。
2. KRT、持續 eGFR<15 與腎因性死亡均未個別確認；不能把「複合終點下降」改寫成「腎衰竭本身已單獨下降」。
3. 各藥物在相符表現型的療效，和「哪個先用、併用是否加成」是兩個問題；前者可有 RCT 支持，後者多仍是 unknown。

核心定位：`FLOW-PRIMARY-2024` Results「Primary Outcomes」journal p.115、Table 2 p.116、Discussion pp.119–120；`FLOW-SUPPLEMENT-2024` Table S2。

## 五個病例：何時最值得考慮 semaglutide

### 病例 A：T2D＋CKD，UACR 800，eGFR 42，肥胖

這是最接近 FLOW 的表現型之一：符合 eGFR 25–<50、UACR >100 的收案路徑，且肥胖提供額外的治療理由。以 FLOW 1.0 mg SC／週在相符族群中的腎臟／CV／死亡結果而言，分級為 **established**。

但兩件事仍要分開：FLOW 劑量不能被假設會帶來 SELECT 2.4 mg 等級的體重結果；高 UACR 的探索性死亡交互作用也不能用來承諾更大的絕對效益，因為沒有 UACR 分層 ARR／NNT。

定位：`FLOW-PROTOCOL-2021` synopsis pp.6–7；`FLOW-PRIMARY-2024` Tables 1–2；`FLOW-CKDSEVERITY-2025` Figures 2–4；`FLOW-CKDSEVERITY-2026-CJASN` Figure 5。

### 病例 B：T2D＋CKD，UACR 150，eGFR 35，已使用 ACEi＋SGLT2i

病人符合 FLOW 路徑，但 UACR 低於典型參與者。對「在 SGLT2i 上增加 semaglutide 的增量硬腎臟效益」而言，分級是 **unknown**：基線 SGLT2i 次族群的五項主要終點 HR 1.07（0.69–1.67），腎臟專屬終點 HR 1.18（0.71–1.98），信賴區間同時容許效益、無效與傷害。另有事後修改之 cystatin-C 五項終點 HR 0.74（0.47–1.16）；它與預設 creatinine-based 1.07 是不同標記、不同終點定義的 estimand，不得平均、拼成區間或互相推翻，反而說明效果量尚未由現有分析識別。

如果病人另有肥胖、血糖、ASCVD 或整體 FLOW 型殘餘風險，仍可依 semaglutide 的整體證據考慮；理由不能寫成「已證明加在 SGLT2i 上可額外預防腎衰竭」。

定位：`FLOW-SGLT2-2024` Figure 1／Table 1／Results。

### 病例 C：T2D，eGFR 25，血糖控制不佳

eGFR 25 正好位於 FLOW 下界；必須先取得 UACR。若 UACR >100 且 <5,000 mg/g，才符合低 eGFR 收案路徑；UACR≤100 則不符合。基線再分類的 UACR<100 次族群只有 350 人，HR 0.70（0.34–1.44），不能建立正常白蛋白尿 CKD 療效。

血糖治療需求本身為 **strongly supported**；若 UACR 符合路徑，FLOW 複合終點效益在 eGFR<30 的資料屬 **suggestive**，因該次族群 HR 0.81（0.58–1.13）仍不精確。eGFR<25 則沒有 FLOW 隨機療效證據。此類病人需要慢滴定，並把 GI 攝取、容積與腎功能監測一起規劃。

定位：`FLOW-PROTOCOL-2021` synopsis pp.6–7；`FLOW-CKDSEVERITY-2026-CJASN` Figures 1–2；安全監測見 `FDA-OZEMPIC-USPI-S038-2026` Warnings「Acute Kidney Injury Due to Volume Depletion」。

### 病例 D：T2D＋CKD，ACEi＋SGLT2i＋finerenone 後仍有白蛋白尿

這是四重治療問題。FLOW 基線 MRA 使用者只有 257 人，幾乎都是 spironolactone／eplerenone，**finerenone 0 人**。因此加上 semaglutide 的直接加成性硬腎臟效益為 **unknown／尚未確立**。

可依病人的其他已證實治療目標考慮 semaglutide，但必須清楚告知：現有支持來自不同藥物各自的 RCT、間接次族群與模型合理性，不是這個四重組合本身的隨機證明。模型化 NNT 不能作為對病人的效果承諾。

定位：`FLOW-MRA-2025` Figure 1／Supplementary Tables 1–2；`COMBO-MODEL-NEUEN-2024` PubMed structured abstract／Results，PMID 37952217。

### 病例 E：T2D＋CKD＋肥胖＋已確立 ASCVD

這名病人同時對應多個證據面向：若符合 FLOW，五項主要複合、MACE 與死亡結果是 **established**；SOUL 支持 T2D 高風險族群 MACE；SELECT 支持其自身 2.4 mg、肥胖／ASCVD 族群的 CV 與體重面向。

但把這些面向合成「同一劑量對同一病人四個領域都有相同幅度效益」，只屬 **suggestive 的跨試驗整合**。主要問題若是白蛋白尿性 CKD，FLOW 1.0 mg 證據最貼近；若主要問題是肥胖／ASCVD，劑量與途徑應依相符試驗判讀，不能把 FLOW、SELECT、SOUL 視為等效。

定位：`FLOW-PRIMARY-2024` Table 2；`SELECT-KIDNEY-2024` Table 1／Results；`SOUL-PRIMARY-2025` PubMed structured abstract／Results。

## 哪些人仍在證據邊界外

| 表現型 | FLOW 狀態 | 目前可說到哪裡 |
|---|---|---|
| 持續 UACR≤100／正常白蛋白尿 CKD | 收案路徑不符 | 只有不精確的基線再分類次族群；直接療效 unknown |
| eGFR>75 或 <25 | 排除 | 無 FLOW 隨機療效證據 |
| 維持性透析／腎移植 | 排除 | 透析只有篩選後持續用藥描述；移植無資料 |
| 第一型糖尿病 | 排除 | unknown |
| 非糖尿病 CKD | 排除 | SELECT／SMART 只提供間接、提示性資料 |
| 腎絲球腎炎、自體免疫腎病、ADPKD／遺傳性腎病 | 排除 | unknown |

## 表現型導向的分層演算法

這是證據組織架構，不是固定階梯，也沒有完成的 RCT 隨機比較四類藥物的先後或完整組合。

### 第一步：先確認是否站在 FLOW 證據內

核對 T2D、eGFR、UACR、ASCVD／HF、肥胖／血糖需求，以及血鉀、容量、營養與功能儲備。eGFR<25、維持性透析、移植或不符合白蛋白尿門檻者，不可套用 FLOW 療效結論。

分級：FLOW 收案邊界為 **established**；超界療效為 **unknown**。

### 第二步：建立腎臟與 HF 基礎

在適應症與耐受允許時確認／優化 RASi，並使用 SGLT2i。SGLT2i 有跨更廣 eGFR、包含非糖尿病 CKD 的專屬硬腎臟結果證據。

分級：各藥物在相符適應症的療效為 **established**；這不是 FLOW 做過的頭對頭排序。

### 第三步：依殘餘風險分流，不硬排成第 3、4 名次

- 持續白蛋白尿、血鉀與 eGFR 適合：finerenone／nsMRA 有其自身糖尿病 CKD 硬終點證據，並需監測血鉀。
- 肥胖、ASCVD、血糖需求、希望減少低血糖負擔，或 FLOW 型殘餘腎臟風險突出：semaglutide 可較早加入；腎臟主張使用 FLOW 驗證的 1.0 mg SC／週，不把 SELECT 或 SOUL 劑量視為等效。

分級：兩種治療在各自相符表現型的療效可為 **established**；finerenone 與 semaglutide 的相對先後為 **unknown**。

### 第四步：需要多藥時，把未知一起開出去

基線 SGLT2i／MRA 次族群未偵測到主要終點顯著異質性，但都不足以證明 semaglutide 的增量硬腎臟效益；FLOW 基線也沒有 finerenone。模型只能說明理論互補，不是療效上限。

分級：直接加成性與最佳排序 **unknown**；模型為 **hypothesis-generating**。

### 第五步：每一次加藥都重新檢查可耐受性

特別在晚期 CKD，追蹤姿勢性症狀、攝取、GI loss、利尿劑／SGLT2i 容積負荷、腎功能、營養與功能；高視網膜風險者安排眼科追蹤。透析病人須把乾體重、體液移除與組織流失分開判讀。

分級：監測原則由仿單與一般臨床實務支持；特定多藥監測門檻未由 FLOW 隨機驗證。

## 最後的共同決策句

對符合 FLOW 的病人，可以有把握地說 semaglutide 已具隨機器官結果證據；同時也要誠實說，個別腎衰竭組成、超出收案範圍的療效，以及與 SGLT2i／finerenone 的加成性仍未被證明。真正的臨床決策，不是替四類藥硬排座次，而是讓腎臟、心血管、血糖、體重、容量、營養、治療負擔與病人價值偏好共同決定順序。
