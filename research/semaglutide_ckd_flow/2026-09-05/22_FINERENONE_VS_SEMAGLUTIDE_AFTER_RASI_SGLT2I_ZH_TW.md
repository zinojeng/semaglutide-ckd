# ARB＋SGLT2i 之後：Semaglutide 或 Finerenone？

> 證據更新：2026-09-07。對象為臨床專業人員；本文是學術證據整理，不是個別病人的醫療建議。ACEi 與 ARB 以下合稱 RASi。請勿在 ACEi 與 ARB 之間做雙重 RAS blockade。

## 先說結論

這不是「哪一顆藥的 HR 比較小」的問題，也不是終身二選一。目前沒有 RCT 直接比較：在已使用最大可耐受 RASi＋SGLT2i 的 T2D＋CKD 病人，下一步隨機加 **semaglutide** 或 **finerenone**，何者有較佳硬腎臟、心血管或死亡結局；也沒有證實兩者合併可帶來加成硬終點效益的試驗。

若只能先選一個，可用以下工作規則：

- **Finerenone-first**：持續 albuminuria 是主要殘餘風險，尤其未符合 FLOW 的 eGFR＋UACR 組合（例如 UACR 30–<100 mg/g，或 eGFR ≥50 且 UACR 100–300 mg/g），但落在 finerenone program；eGFR ≥25、血鉀在可起始範圍且能完成監測；或合併 HFmrEF/HFpEF、臨床目標偏向降低 worsening-HF events。
- **Semaglutide-first**：除 CKD 外，尚有未控制高血糖、肥胖或 MASLD；ASCVD／多面向體重與代謝效益是主要目標；或血鉀 >5.0 mEq/L（對 K⁺ 數值等同 mmol/L）、無法可靠監測血鉀，使 finerenone 暫不適合。
- **沒有自動答案的重疊帶**：先同時核對 eGFR＋UACR；FLOW 納入 eGFR 25–<50 且 UACR >100，或 eGFR 50–75 且 UACR >300 mg/g。符合 FLOW 組合者與 finerenone program 有直接證據重疊，但 100 或 300 都不是生物學二分點；應再看血鉀、HF、ASCVD、體重、HbA1c、MASLD、GI／營養風險、成本與病人偏好。
- **最後常是兩者都需要**：先後順序是實務上的 adverse-effect attribution 與監測安排，不代表療效排名。若兩者皆有適應理由，可先啟動表現型最迫切的一項，約 4 週完成耐受性／實驗室評估後再評估另一項；這是務實流程，不是已驗證的 sequencing strategy。

2026 AHA/ACC/ADA/ASN CKM 指引給出目前最直接的表現型語句：在 RASi＋SGLT2i 後仍有 persistent albuminuria，可增加 finerenone 和／或具有實證的 GLP-1–based therapy；若另有 uncontrolled hyperglycemia、obesity 或 MASLD，可優先 semaglutide。這是 guideline-directed prioritization，仍不是 head-to-head superiority proof。[CKM-GUIDELINE-2026, §5.5.4, pp.40–43；DOI 10.1016/j.jacc.2026.03.056](https://www.jacc.org/doi/10.1016/j.jacc.2026.03.056)

核對紀錄：2026-09-07 重新開啟 JACC accepted author manuscript，直接核對 §5.5.4 的 recommendations、Synopsis 與 recommendation-specific supportive text（pp.40–43）；公開文件只轉述決策邏輯，不重製受限制全文。

## 研究結果到底差在哪裡？

| 問題 | Semaglutide | Finerenone | 對本題的意義 |
|---|---|---|---|
| 代表性 RCT | FLOW，N=3,533，semaglutide 1.0 mg SC weekly vs placebo | FIDELIO-DKD／FIGARO-DKD；FIDELITY 預設 pooled N=13,026 | 都是在 RASi 背景下的器官保護試驗，但不是彼此對照 |
| 族群 | T2D＋albuminuric CKD；eGFR 50–75 時 UACR >300–<5,000，或 eGFR 25–<50 時 UACR >100–<5,000 | T2D＋CKD；FIDELIO／FIGARO 互補涵蓋 UACR 30–5,000、eGFR ≥25 的多個路徑 | UACR 30–<100 的直接試驗匹配較偏 finerenone；UACR >100 多為重疊區 |
| 主要終點 | FLOW 五項複合：腎衰竭、持續 eGFR 下降 ≥50%、腎因死亡或 CV death；HR 0.76（0.66–0.88） | FIDELIO：腎衰竭、持續 eGFR 下降 ≥40% 或腎因死亡；HR 0.82（0.73–0.93）。FIDELITY kidney composite（≥57% eGFR decline）HR 0.77（0.67–0.88） | FLOW primary **含 CV death**；Finerenone kidney endpoint 不含 CV death，不能直接比較 0.76、0.82、0.77 |
| 腎臟專屬／CV | FLOW 四項 kidney-specific composite HR 0.79（0.66–0.94）；MACE HR 0.82（0.68–0.98）；all-cause death HR 0.80（0.67–0.95） | FIDELITY CV composite HR 0.86（0.78–0.95）；kidney composite HR 0.77（0.67–0.88）；ESKD HR 0.80（0.64–0.99） | Semaglutide 同時處理 glucose、weight、ASCVD；finerenone 的 dedicated albuminuric-CKD 與 HF pathway 較直接 |
| 現代背景治療 | FLOW baseline SGLT2i 15.6%（550 人）；主要終點 HR 1.07（0.69–1.67）vs 未使用者 0.73（0.63–0.85），P-interaction=.109 | FIDELITY baseline SGLT2i 6.7%；效果未見顯著 interaction，但背景藥未隨機 | 兩套 program 都沒有充分回答「已穩定用 SGLT2i 後的增量硬終點」；null interaction 不等於證實加成 |
| 與另一藥合併 | FLOW baseline MRA 257 人，主要為 spironolactone；**finerenone 0 人** | FIDELITY baseline GLP-1RA 7.2%；GLP-1RA 種類／劑量不一且未隨機 | 兩個 subgroup 問題方向相反，都不是 semaglutide＋finerenone RCT |
| 主要不良反應／負擔 | GI 症狀、食慾與體重下降、脫水時 prerenal AKI；既往 retinopathy 須監測；嚴重 gastroparesis 不建議 | Hyperkalemia、初期 eGFR dip、CYP3A4 interactions；需規律 K⁺／eGFR | 安全表現型常比 UACR 的單一數字更能決定誰先用 |

來源定位：`FLOW-PRIMARY-2024`（[NEJM 2024](https://www.nejm.org/doi/full/10.1056/NEJMoa2403347), Table 2／Figures 1–2）；`FLOW-SGLT2-2024`（[Nature Medicine 2024](https://www.nature.com/articles/s41591-024-03133-0), Figures 1–3／Table 1）；`FIDELIO-DKD-2020`（[NEJM 2020](https://www.nejm.org/doi/full/10.1056/NEJMoa2025845)）；`FIGARO-DKD-2021`（[NEJM 2021](https://www.nejm.org/doi/full/10.1056/NEJMoa2110956)）；`FIDELITY-POOLED-2022`（[Eur Heart J／PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC8830527/), Tables 1–2／Figures 1–3）。

## 為什麼不能拿 HR 做藥物排行榜？

1. FLOW primary 把 CV death 放進複合終點；FIDELIO／FIDELITY kidney composite 沒有。
2. FLOW 的 eGFR decline 門檻是 ≥50%；FIDELIO primary 是 ≥40%，FIDELITY 是 ≥57%。
3. 族群的 eGFR、UACR、ASCVD、HF 與背景 SGLT2i 比例不同。
4. 不同 acute eGFR phase、follow-up、competing-risk 處理與試驗年代，會改變 HR 的語境。
5. 「一組顯著、另一組不顯著」不等於兩藥效果不同；需要同一個隨機化比較或正式 interaction evidence。

因此本文只做 **trial-by-question** 對讀，不做 efficacy league table。

## 決策演算法：已用 RASi＋SGLT2i 後

### Step 1｜先確認不是「還沒把地基做好」

- RASi 已達最大可耐受劑量，血壓與容量狀態合宜。
- SGLT2i 已使用／可耐受；不要因 HbA1c 已達標就停掉器官保護思考。
- 以至少兩次 UACR（排除感染、劇烈運動、失代償 HF 等暫時因素）、eGFR trajectory 與 K⁺ 確認殘餘風險。
- 同時盤點 ASCVD、HF phenotype、BMI／腰圍、HbA1c、MASLD、frailty／sarcopenia、GI disease、retinopathy、費用與偏好。

### Step 2｜用「主要未解決問題」分流

| 主要臨床問題 | 較可辯護的第一選擇 | 理由與邊界 |
|---|---|---|
| UACR 30–<100 mg/g 持續、eGFR≥25、K⁺適合 | **Finerenone-first** | 在 FIDELIO/FIGARO/FIDELITY 與 ADA nsMRA 邏輯內；低於 FLOW protocol 的 UACR 下界 |
| 符合 FLOW 的 eGFR＋UACR 組合，且沒有明顯代謝或安全偏向 | **無已證實勝者** | 與 finerenone program 有直接證據重疊；不要用 100 或 300 單獨當生物學斷點 |
| eGFR≥50、UACR 100–300 mg/g | **偏 Finerenone-first** | 落在 finerenone program，但不符合 FLOW 的 eGFR＋UACR 納入組合；不代表 semaglutide 因其他代謝／CV 適應理由不能使用 |
| Persistent albuminuria＋未控制高血糖／肥胖／MASLD | **Semaglutide-first 或兩者快速序列加入** | 2026 CKM 指引明確允許 semaglutide 優先；finerenone 的 albuminuria indication 仍在，不是被取代 |
| K⁺>5.0 mEq/L 或 K⁺ monitoring 不可靠 | **Semaglutide-first** | FDA finerenone 標示：K⁺>5.0 不起始；先處理高血鉀與可逆因素 |
| 嚴重 gastroparesis、反覆 GI intolerance、低體重、frailty／sarcopenia 或營養風險 | **若 K⁺／eGFR 合宜，偏 Finerenone-first** | 避免加劇攝食下降、脫水與 lean-mass concern；仍需個別化，不是 GLP-1RA 絕對禁忌的擴張 |
| 既往 diabetic retinopathy，預期 HbA1c 快速下降 | **兩藥皆可，但 semaglutide 要加強眼科與降糖速度管理** | Retinopathy history 是監測訊號，不應被寫成一律禁用 |
| HFmrEF/HFpEF，目標是減少 worsening-HF events | **偏 Finerenone-first** | FINEARTS-HF 對 total worsening-HF events＋CV death 有 hard-event evidence；不能把此結果外推成所有低 UACR HF 都有 kidney benefit |
| Obesity-related HFpEF，目標是症狀、功能與體重 | **偏 Semaglutide-first** | STEP-HFpEF program 主要回答 KCCQ、功能與體重；與 FINEARTS 的 hard-event estimand 不同 |
| eGFR<25 或 dialysis | **不要以兩套 kidney-outcome RCT 宣稱起始效益** | FLOW 與 finerenone outcome trials 的起始下界皆為 eGFR 25；GLP-1RA 可因 glycemic/CV 目的個別使用，但 kidney-outcome 外推須清楚標示 |

FINEARTS-HF 定位：[NEJM 2024，DOI 10.1056/NEJMoa2407107](https://www.nejm.org/doi/full/10.1056/NEJMoa2407107)。STEP-HFpEF 定位：[NEJM 2023，DOI 10.1056/NEJMoa2306963](https://www.nejm.org/doi/full/10.1056/NEJMoa2306963)。兩者不可因都叫 HFpEF 就合併成同一效果量。

### Step 3｜若兩者都需要，如何排程？

沒有證據支持固定「第三、第四支柱」的療效排序。可採以下務實做法：

1. 先處理近期風險最高且可安全執行的表現型。
2. 若先加 finerenone：起始前查 K⁺／eGFR，約 4 週後及每次調整後複查，再依風險定期監測。FDA 現行標示是 **K⁺>5.0 mEq/L 不起始**；FIDELIO／FIGARO 的 K⁺≤4.8 mmol/L 是試驗入選條件，兩者不可混寫。[FDA Kerendia USPI 2026, §§2.1–2.3, 5.1](https://www.accessdata.fda.gov/drugsatfda_docs/label/2026/215341Orig1s009lbl.pdf)
3. 若先加 semaglutide：由低劑量逐步 titrate；若有持續噁心、嘔吐、腹瀉或食量顯著下降，評估 volume、eGFR、營養與其他降糖藥；insulin／SU 可能需調整。CKD hard-outcome 對應的是 FLOW 的 1.0 mg SC，不要把 SELECT／STEP-HFpEF 的 2.4 mg 證據直接互換。[FDA Ozempic USPI 2026, §§1–2, 5](https://www.accessdata.fda.gov/drugsatfda_docs/label/2026/209637s038lbl.pdf)
4. 第一項耐受且另一表現型仍有治療理由時，可加入第二項；同時向病人說明：機轉互補與 guideline layering 合理，但 semaglutide＋finerenone 的增量硬腎臟效益尚未被直接隨機驗證。

## CONFIDENCE 改變了什麼？沒有改變什麼？

CONFIDENCE 將已用 RASi、eGFR 30–90、UACR 100–5,000 mg/g 的 T2D＋CKD 病人隨機分為 finerenone、empagliflozin 或兩者同步起始。818 人隨機化，800 人進入 efficacy analysis；180 天時，合併組的 UACR 降幅較 finerenone 單藥多 29%（ratio 0.71，95% CI 0.61–0.82），較 empagliflozin 單藥多 32%（0.68，0.59–0.79），均 P<.001。[CONFIDENCE-2025, NEJM, DOI 10.1056/NEJMoa2410659](https://www.nejm.org/doi/full/10.1056/NEJMoa2410659)

它直接支持的是 **180 天 albuminuria surrogate 與短期 safety**，因此促成 ADA 2026 Recommendation 11.9：特定 RASi 背景、UACR≥100、eGFR 30–90 的成人可考慮同步 SGLT2i＋finerenone。它沒有 semaglutide arm，也沒有檢定 kidney failure、MACE 或 mortality 的長期加成效益；不能用來宣稱 finerenone「打敗」semaglutide。

## 2026 新資料：FIND-CKD 與 INFINITY

- FIND-CKD 在 **無糖尿病**、albuminuric CKD、RASi 背景的 1,584 人中，finerenone 使 32 個月 total eGFR slope 每年少下降 0.7 mL/min/1.73m²（95% CI 0.3–1.1）；kidney-or-CV composite HR 0.77（0.60–0.99），但 kidney-only composite HR 0.78（0.60–1.01）。這擴充 finerenone 的疾病範圍，卻沒有回答 T2D＋CKD 已用 SGLT2i 後與 semaglutide 的排序。[FIND-CKD-2026, NEJM, DOI 10.1056/NEJMoa2604625](https://www.nejm.org/doi/full/10.1056/NEJMoa2604625)
- INFINITY 是 FIDELIO-DKD、FIGARO-DKD、FIND-CKD 的 prespecified individual-participant pooled analysis，不是新的 combination randomization；它支持 finerenone 跨 albuminuric CKD spectrum 的一致性，但不能把「SGLT2i subgroup 無顯著 interaction」升格為 additivity proof。[INFINITY-2026, Lancet, DOI 10.1016/S0140-6736(26)01009-3／PMID 42248158](https://pubmed.ncbi.nlm.nih.gov/42248158/)

## 指南如何說

- **ADA 2026 11.7a／11.7b**：T2D＋CKD 使用有實證的 SGLT2i；也推薦有此族群實證的 GLP-1 agonist 以降低 CKD progression 與 CV risk。
- **ADA 2026 11.8**：CKD＋albuminuria、eGFR≥25，推薦有 outcome evidence 的 nsMRA；起始 1 個月後監測 K⁺。
- **ADA 2026 11.9**：在 RASi 背景、UACR≥100、eGFR 30–90，可考慮同步 SGLT2i＋finerenone，理由是 short-term safety 與 albuminuria benefit。
- **2026 CKM guideline**：RASi＋SGLT2i 是 CKD＋T2D／albuminuria 的 first-line foundation；persistent albuminuria 時增加 finerenone 和／或 GLP-1–based therapy。Semaglutide 在 uncontrolled hyperglycemia、obesity 或 MASLD 可優先於 finerenone。
- **KDIGO 2026 Diabetes-CKD update**：截至本文日期仍應標為 public-review draft，而不是 final guideline；final status 需日後重查。[KDIGO topic page](https://kdigo.org/guidelines/diabetes-ckd/)

ADA 2026 原文定位：[Chapter 11, DOI 10.2337/dc26-S011](https://doi.org/10.2337/dc26-S011)。指引提供 decision framework；沒有把兩藥做 head-to-head efficacy ranking。

## 三個病例，示範怎麼想

### 病例 A｜UACR 70、eGFR 42、K⁺ 4.4；HbA1c／體重已達標

若 albuminuria 經確認仍持續，這個表現型較支持 finerenone-first：落在 finerenone program 與 ADA 11.8，卻低於 FLOW protocol 的 UACR >100 下界。仍需確認 eGFR／K⁺、交互作用與監測能力。

### 病例 B｜UACR 450、eGFR 45、K⁺ 4.5；BMI 36、HbA1c 9.2%、MASLD

兩藥皆有理由。2026 CKM framework 支持 semaglutide-first，因它同時處理高血糖、肥胖、MASLD 與 FLOW-like CKD risk；albuminuria 持續且 K⁺可接受時，再快速評估加入 finerenone。不能把此順序稱為 semaglutide 腎臟療效較強。

### 病例 C｜UACR 220、eGFR 31、K⁺ 5.2 mEq/L；低 BMI、反覆噁心

Finerenone 因 K⁺>5.0 暫不宜起始；semaglutide 又有 GI／營養風險。這不是硬選其中一個，而是先處理 hyperkalemia、檢視藥物與飲食、評估容量及營養，再重新決策。風險很高不代表要忽略兩邊的安全邊界。

## 證據分層

### Established

- Semaglutide 在 FLOW 型 T2D＋albuminuric CKD 降低含 CV death 的五項主要複合終點，且 kidney-specific composite、MACE、all-cause death 方向一致。
- Finerenone 在 T2D＋albuminuric CKD、RASi 背景下降低 dedicated kidney 與 CV composites；需要 K⁺／eGFR safety monitoring。
- CONFIDENCE 證實 finerenone＋empagliflozin 同步起始可比任一單藥帶來更大 180 天 UACR 降幅。

### Supported／guideline-directed，但不是 head-to-head proof

- 依 persistent albuminuria、K⁺／eGFR、obesity、glycemia、MASLD、ASCVD、HF 與病人偏好做 phenotype-guided prioritization。
- 在兩者皆有理由時，最終 layering 兩項治療，而不是把第一次選擇視為永久互斥。

### Unknown

- Semaglutide-first vs finerenone-first 的比較效果。
- Semaglutide＋finerenone 的 additive hard-kidney、MACE、HF 或 mortality benefit。
- 最佳起始間隔、四藥同步起始的安全性與成本效益。
- eGFR<25、maintenance dialysis、nonalbuminuric CKD 的 kidney-outcome efficacy。

本專題由 Codex root coordinator 擔任 reconciler，使用三個持續、彼此分離的唯讀 Claude Code sessions：nephrology、endocrine/CKM、methods red-team。第一輪各自查閱本 repository 與 Mac mini 的 `nsmra` 資料；第二輪由兩個臨床角色互讀對方結論並回應方法學挑戰；第三輪由 methods session 裁決。建立 `22_` extension 與更新 source ledger 是本次使用者明確委託下的 reconciler 工作，不是 lane session 寫入。

交叉討論實際改動了四點：

1. 撤回「UACR≥300 才 finerenone-first」的過度簡化，改為同時依 eGFR＋UACR 判斷：未符合 FLOW 組合者較偏 finerenone evidence；符合 FLOW 組合者才是兩套直接證據的重疊帶。
2. 分開試驗 K⁺≤4.8 入選條件與 FDA K⁺>5.0 不起始標示。
3. 分開 FINEARTS-HF hard events 與 STEP-HFpEF symptoms／weight estimands。
4. 把 FIND-CKD／INFINITY 定位為 finerenone evidence expansion，而非 SGLT2i additivity 或 semaglutide sequencing proof。

角色共識只用來找錯與校準語句；所有臨床結論仍以原始試驗、正式指引與官方標示為依據。

## 最後可帶走的五句話

1. **RASi＋SGLT2i 後沒有一個普遍適用的第三名。**
2. **UACR 30–<100 比較偏 finerenone evidence；UACR>100 是否進入直接證據重疊區仍要合併 eGFR 判讀，不用 300 單獨當硬切點。**
3. **高血糖、肥胖或 MASLD 讓 semaglutide 優先；高 K⁺讓 finerenone 延後；嚴重 GI／營養風險則反過來。**
4. **HF 要先問目標：hard worsening-HF events 與 obesity-related symptoms／weight 不是同一個 estimand。**
5. **最合理的終點常是兩者都用，但「合理併用」仍不等於「加成硬終點已證實」。**
